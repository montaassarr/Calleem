================================================================================
                      📦 QUICK INSTALL COMMANDS
================================================================================

# Backend (Python) - Create virtual environment first
python3 -m venv venv
source venv/bin/activate  # On Ubuntu/Linux
pip install --upgrade pip

# Install all backend dependencies at once
pip install fastapi uvicorn[standard] pydantic python-dotenv twilio requests \
            aiohttp python-multipart passlib[bcrypt] python-jose[cryptography] \
            websockets pymongo motor dnspython groq langchain transformers \
            torch sentencepiece gunicorn celery pytest black flake8

# Frontend (Node.js) - Navigate to frontend folder first
cd frontend
npm create vite@latest . -- --template react
npm install
npm install -D tailwindcss postcss autoprefixer
npm install axios react-router-dom framer-motion socket.io-client \
            lucide-react date-fns react-hot-toast

# Initialize Tailwind CSS
npx tailwindcss init -p

# System tools (Ubuntu)
sudo apt update
sudo apt install -y docker.io docker-compose nginx redis-server

Before running the application, ensure:

□ Virtual environment activated         source venv/bin/activate
□ All Python packages installed         pip list

================================================================================
                      🚀 QUICK START COMMANDS
================================================================================

# 1. Backend Setup
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your actual credentials
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 2. Frontend Setup (in new terminal)
cd frontend
npm install
npm run dev

# 3. Access the application
# Backend API: http://localhost:8000
# Frontend Dashboard: http://localhost:5173
# API Docs: http://localhost:8000/docs
